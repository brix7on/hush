# hush — разработка

## Структура

```
src/
  main.rs            точка входа
  lib.rs             версия, общие модули
  dsp/               подавитель наводки, шумодав, эквалайзер, AGC, усилитель, БПФ
  pipe/              шкала времени потоков, движок обработки, вывод с запасом буфера, вырезка записи
  audio/             форматы WASAPI, ресемплер, WAV
  diag.rs            тестовый сигнал и его поиск в записи
  panel.rs           раскладка и отрисовка панели (без Windows, тестируется везде)
  glyphs.rs          пиксельные значки (генерируется tools/art/icons.py)
  lang.rs            язык интерфейса: l("рус", "eng"), lf!(...)
  win/               программа для Windows
    app.rs           запуск, флаги, настройки, сессия, калибровка, запись
    capture.rs       захват микрофона и loopback наушников
    render.rs        вывод в кабель, проигрывание звуков
    dev.rs           устройства, форматы, монопольный режим, сессии
    ui.rs            окно панели, значок и меню в трее
    ptt.rs           микрофон по кнопке и звуковые сигналы
    update.rs        самообновление: релиз GitHub → hush.exe + SHA256SUMS → подмена через .old → -after-update
    doctor.rs        режим -doctor: откуда берётся эхо
    sys.rs           время, файлы, журнал, консоль, автозапуск, один экземпляр
    state.rs         общие счётчики и события
assets/              фон панели, значок, манифест
tools/art/           генераторы фона и значков
tests/               поведение ядра; golden.rs сверяет с эталонными выходами (HUSH_GOLDEN=папка)
```

## Поток звука

Микрофон и loopback наушников захватываются в отдельных потоках (`run_capture`) и кладутся на общую шкалу времени по меткам QPC (`pipe::StreamIn`). Поток вывода (`run_render`) раз в ~1 мс забирает готовые блоки у движка (`pipe::Engine`), тот прогоняет их через подавитель, шумодав, эквалайзер, AGC и усилитель и отдаёт в кабель через `pipe::Sink`, который держит небольшой запас буфера. Потеря устройства, выход из сна или смена устройства по умолчанию пересобирают всю цепочку.

## Интерфейс

Панель рисуется в 1-битной гамме Gust (`#0a0a0b` и `#ded8ca`) в собственный буфер пикселей (`panel.rs`), подписи выводит GDI шрифтом без сглаживания. Превью без Windows:

```sh
HUSH_PREVIEW=/tmp/panel cargo test --lib panel_preview
```

пишет `/tmp/panel.rgb` (600×580, RGB) и `/tmp/panel.txt` (подписи с координатами).

`HUSH_UIDEMO=1 hush.exe` открывает панель с выдуманными уровнями без звука. `HUSH_LANG=en` или `ru` переключает язык.

## Сборка и тесты

```sh
./build.sh
```

Вручную:

```sh
cargo test --release
HUSH_VERSION=dev cargo build --release --target x86_64-pc-windows-gnu
```

Значок, манифест и сведения о версии собираются `build.rs` из `assets/` (нужен `windres` из MinGW-w64). Версия берётся из `HUSH_VERSION`, в релизе CI подставляет её из тега. Теги с дефисом (`v2.0.0-rc.1`) выходят пред-релизами: самообновление их не предлагает.
