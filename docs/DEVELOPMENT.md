# hush — разработка

## Структура

```
cmd/hush/              программа для Windows
  main_windows.go      запуск, флаги, сессия захвата и вывода, калибровка
  app_windows.go       папка данных, перенос старых настроек, консоль, один экземпляр
  ui_windows.go        окно панели, значок и меню в трее, автозапуск
  panel.go             раскладка и отрисовка панели (без Windows, тестируется везде)
  glyphs.go            пиксельные значки (генерируется tools/art/icons.py)
  scene.png            фон панели (генерируется tools/art/scene.py)
  lang.go              язык интерфейса: L("рус", "eng")
  ptt_windows.go       микрофон по кнопке и звуковые сигналы
  power_windows.go     сон ПК при долгой тишине
  doctor_windows.go    режим -doctor: откуда берётся эхо
  winres/              значок, манифест и сведения о версии exe
internal/aec/          подавитель наводки, адаптивный фильтр, шумодав, БПФ
internal/pipe/         шкала времени потоков, движок обработки, вывод, усиление, AGC, эквалайзер
internal/audio/        форматы WASAPI, ресемплер, WAV
internal/diag/         тестовый сигнал и его поиск в записи
tools/art/             генераторы фона и значков
```

## Поток звука

Микрофон и loopback наушников захватываются в отдельных потоках (`runCapture`) и кладутся на общую шкалу времени по меткам QPC (`pipe.StreamIn`). Поток вывода (`runRender`) раз в ~1 мс забирает готовые блоки у движка (`pipe.Engine`), тот прогоняет их через подавитель, шумодав, эквалайзер, AGC и усилитель, и отдаёт в кабель через `pipe.Sink`, который держит небольшой запас буфера. Потеря устройства, выход из сна или смена устройства по умолчанию пересобирают всю цепочку.

## Интерфейс

Панель рисуется в 1-битной гамме Gust (`#0a0a0b` и `#ded8ca`) в собственный буфер пикселей (`panel.go`), подписи выводит GDI шрифтом без сглаживания. На мониторах от 175% масштаба панель увеличивается ровно вдвое. Превью без Windows:

```sh
HUSH_LANG=ru HUSH_PREVIEW=/tmp/panel go test -run TestPanelPaint ./cmd/hush
```

пишет `/tmp/panel.png` (фигуры) и `/tmp/panel.json` (подписи с координатами).

`HUSH_UIDEMO=1 hush.exe` открывает панель с выдуманными уровнями без звука. `HUSH_LANG=en` или `ru` переключает язык.

## Сборка и тесты

```sh
./build.sh
```

Вручную:

```sh
go test -race -short ./...        # -short пропускает долгие симуляции
go test ./...                     # все тесты, несколько минут
GOOS=windows GOARCH=amd64 go build -trimpath -ldflags "-H=windowsgui -s -w" -o dist/hush.exe ./cmd/hush
```

Тесты на реальных записях включаются переменной `REC_WAV=путь.wav` (запись из `-record`).

Значок и манифест: `cmd/hush/rsrc_windows_amd64.syso`, собирается из `cmd/hush/winres` утилитой `go-winres`. В релизе CI пересобирает его с номером версии из тега.

`golang.org/x/sys` подменён зеркалом `github.com/golang/sys` (директива `replace` в `go.mod`) на случай, если `golang.org` недоступен.
